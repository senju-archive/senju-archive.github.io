# お問い合わせ

<div class="archive-status">公式連絡窓口は開設準備中です</div>

千手氏歴史アーカイブでは、史料の所在に関する情報や記事の訂正、関係する地域史・家系史についてのご連絡を受け付ける窓口を準備しています。

## 予定しているお問い合わせの内容

- **史料・関連情報の提供**：公開されている文献の所在、古文書・系譜資料についての情報
- **記事の訂正・ご指摘**：人名・地名の表記、出典、年代、同定上の論点
- **調査・取材・連携に関するご相談**：地域史・関連史料などについてのご連絡

## 現在の受付状況

**専用メールアドレスとお問い合わせフォームは、まだ公開設定されていません。** 現時点でこのページから送信はできません。利用可能な窓口の準備と動作確認が済み次第、ここに掲載します。

ご連絡内容や提供資料に含まれる個人情報は、原則として公開ページや公開GitHubリポジトリには掲載しない方針です。ご提供者の氏名等を紹介する場合は、事前に確認します。
