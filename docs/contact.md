# お問い合わせ

<div class="archive-status">Googleフォームによるお問い合わせ窓口</div>

千手氏歴史アーカイブでは、千手氏に関係する史料の所在、記事の訂正、郷土史・家系史・研究に関する情報やご相談を受け付けるため、お問い合わせフォームを設置しています。

## お問い合わせフォーム

**[千手氏歴史アーカイブ｜お問い合わせフォームを開く](https://forms.gle/qNBf9NBxYF6PX17i8)**

上のリンクからGoogleフォームに移動し、お問い合わせ内容を入力してください。フォームはGoogleのサービス上で開きます。

## お問い合わせいただける内容

- **史料・関連情報の提供**：公開されている史料の所在、古文書・系譜資料、千手氏や関連地域の情報
- **記事の訂正・ご指摘**：人名・地名の表記、出典、年代、人物・系統の同定に関するご指摘
- **調査・研究に関するご相談**：地域史・郷土史・関連史料の調査、研究交流に関するご連絡
- **その他**：当アーカイブに関するお問い合わせ

お問い合わせの際は、関連するページのURLや、確認できる資料名・出典などを添えていただくと、内容の確認に役立ちます。

## ご連絡に関するお願い

お問い合わせの内容は確認・返信および情報の検証に利用します。お名前やメールアドレス、未公開の資料情報などを、事前の確認なく公開サイトや公開GitHubリポジトリへ掲載することはありません。

資料画像や個人情報を含むファイルを送付する必要がある場合は、最初の連絡では概要だけを記し、送付方法を個別に相談してください。

専用メールアドレスの直接公開は、必要に応じて今後検討します。
