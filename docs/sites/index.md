# 城郭・史跡・遺跡から探す

<div class="archive-status">関連事典内の史跡索引 ／ 調査・掲載準備中</div>

このページは[千手氏 関連事典](../encyclopedia/)の**城郭・史跡・寺社**を扱う索引です。以前の「史跡から探す」と同じURLを維持しているため、既存のリンクも使えます。

千手氏に関わる城郭・史跡・寺社・遺物の位置、現状、史料、調査記録を整備していきます。

## 掲載予定の調査対象

- **千手城**：筑前千手氏と南北朝期の軍忠に関わる史跡
- **香春岳城（鬼ヶ岳城）**：豊前香春千手氏の伝承に関係する城郭

**いずれも個別記事はまだ未公開です。** 現地調査・史料照合が済んだことを意味しません。

各記事では所在地（公開可能な範囲）、歴史地理、遺構・現状、調査日、利用許諾のある写真、関連人物・事件・史料を扱います。私有地・墓所・立入制限のある場所は公開範囲と位置情報に配慮します。

その場所で起きた出来事は[事件・合戦](../events/)へ、地域全体の説明は[関連事典](../encyclopedia/)へつなぎ、記事の重複を避けます。
