# このサイトについて

**千手氏歴史アーカイブ**は、千手氏に関する古文書・古記録・系図・郷土史や、人物・地域・史跡の情報を紹介する、個人による非営利の歴史資料編纂プロジェクトです。

## 目的

一般の方が千手氏の歴史に親しめること、歴史を研究する方が記載の根拠となる史料をたどれることを目指しています。後世の伝承や系図の記述も紹介しながら、同時代の記録と区別して考えます。

## 運営について

個人による調査・編纂活動として運営しています。公的機関や大学の公式事業ではありません。史料の所在や記事内容については[お問い合わせフォーム](../contact.md)からご連絡いただけます。

## 史料と引用

資料の原文・翻刻・現代語訳や研究上の解釈は、それぞれの出典を示して紹介します。図版や文献の利用条件、情報提供者のプライバシーにも配慮します。

詳しくは[編纂方針](../guides/editorial-policy.md)と[引用・利用案内](../guides/citation.md)をご覧ください。

## ロゴについて

このサイトの蓮華ロゴは、千手氏歴史アーカイブのために現代制作した識別マークであり、千手氏に伝来した家紋や旗印ではありません。深緋と金茶は平家の軍旗から着想を得た意匠ですが、**千手氏の平家出自**を証明するものではありません。
