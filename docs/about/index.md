# このサイトについて

<div class="archive-status">構築中の試験公開</div>

**千手氏歴史アーカイブ** は、千手氏に関わる史料・系統・人物・地域の歴史を、出典にたどれる形で整理する非営利の歴史資料編纂プロジェクトです。

## 基本方針

- 史料の記載、伝承・由緒、推定・考察、未確認事項を区別します。
- 一般の読者には全体像を、詳しく調べる方には典拠への入口を示します。
- 人物・事件・系統・文献・史跡を、可能な範囲で相互に結び付けます。
- 公開前の原稿、未許諾資料、個人情報は公開リポジトリへ置きません。

## 現在の公開状態

このWebサイトはレイアウトと操作性を確認するための仮公開です。内容が整った段階で正式な公開案内を掲載します。
