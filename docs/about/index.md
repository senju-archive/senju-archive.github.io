# このサイトについて

<div class="archive-status">サイト構築中・試験公開</div>

**千手氏歴史アーカイブ**は、千手氏に関する歴史史料・人物・系統・史跡などを整理し、日本史の流れの中で関係をたどれる形で公開する、個人による非営利の歴史資料編纂プロジェクトです。

## 目的

千手氏の諸系統について、後世の伝承だけでなく、古文書・古記録・系図・郷土史・現地調査などの資料を参照しながら、調べた内容と典拠を分かりやすくまとめることを目指します。

歴史の専門知識がない方にも読みやすく、史料を詳しく検討したい方にも原資料を追跡しやすい構成を大切にします。

## 運営について

現在は個人による調査・編纂活動として運営し、記事の編纂・翻刻・現代語訳などの担当や改訂履歴を可能な範囲で記録します。公的機関や大学の公式事業ではありません。

編纂責任者の公開名義は整備中です。お問い合わせは[専用のGoogleフォーム](../contact.md)で受け付けます。未確認の氏名やメールアドレスは掲載しません。

## 史料の扱い

史料の原記載、伝承、推定・考察、未確認事項を区別して示します。権利確認前の画像や個人情報、非公開の研究ノートは公開しません。

詳しくは[編纂方針](../guides/editorial-policy.md)と[引用・利用案内](../guides/citation.md)をご覧ください。
