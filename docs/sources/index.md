# 史料から探す

<div class="archive-status">構築中・公開史料の照合中</div>

文献単位の解題（DOC）と、各史料に現れる個別記載（SENJU）を区別して閲覧できるように準備しています。

公開時には、可能な範囲で原文・翻刻・現代語訳・出典・異説・関連人物を相互に結び付けます。未確認の内容を確定事項として掲載しません。

**研究用データベースに登録した内容が、そのまま自動公開されることはありません。** 公開前に原資料・出典・権利関係を確認します。

## レイアウトの確認

- [文献解題（DOC）の表示見本を見る](../previews/doc/)
- [個別史料記録（SENJU）の表示見本を見る](../previews/senju/)

DOCは文献全体、SENJUはその文献中の個別の記述を扱います。表示見本に実史料は入れていません。
