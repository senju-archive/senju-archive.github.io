# 史料から探す

千手氏に関わる古文書・古記録・系図・郷土史について、記載内容と資料の所在をたどるための入口です。史料が成立した時代や伝来の経緯にも目を向け、人物や出来事の背景を探ります。

## 史料の種類

- **古文書・古記録**：同時代の人物・所領・軍事活動などを知る手がかり。
- **系図・家譜**：家に伝わる系譜や由緒を記した資料。成立時期や異本によって記載が異なる場合があります。
- **地誌・郷土史**：地域の地名・城郭・寺社・伝承などをまとめた文献。

史料の一節を読む際は、書名、記載の年代、原文・翻刻の別、参照した底本を確かめることが重要です。
