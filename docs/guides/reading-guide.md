# 初めての方へ

千手氏歴史アーカイブでは、歴史の概要から人物・史料まで、関心に合わせて読み進められます。

## 千手氏の歴史を知る

まずは[千手氏とは](../senju/)で、主な記録、伝承、四つの地域別の系統についてご覧ください。

## 時代からたどる

[時代から探す](../periods/)では、平安・鎌倉・南北朝・室町・戦国・江戸など、時代ごとに関係する記録をたどれます。[並列年表](../timeline/)は日本史と千手氏の各系統を同じ時間軸で見る入口です。

## 系統・地域から調べる

[系統・地域から探す](../lineages/)では、**筑前嘉麻千手氏、豊前香春千手氏、日向高鍋千手氏、肥前小城千手氏**の概要に進めます。

## 人物・史料を探す

[人物から探す](../persons/)では、千手姓の人物を系統別・五十音順に探せます。

[史料から探す](../sources/)では、古文書・古記録・系図・郷土史の種類や記載内容をたどれます。実際の所蔵先やデジタル公開資料は[関連機関・史料調査リンク](../links/)もご利用ください。

## 地名・史跡・用語から探す

[関連事典](../encyclopedia/)では、嘉麻・香春・高鍋・小城などの地名、千手城などの史跡、関連氏族や歴史用語を扱います。同じ主題のページは[関連タグ](../tags/)からも探せます。

史料の記載、後世の伝承、研究上の解釈については、[編纂方針](editorial-policy.md)もご覧ください。
