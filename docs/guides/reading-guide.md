# 初めての方へ

<div class="archive-status">案内ページ公開中 ／ 史料本文は順次整備中</div>

千手氏歴史アーカイブは、千手氏の歴史を、**日本史の流れ・系統の広がり・人物・原史料**から調べられるようにする非営利の史料編纂サイトです。

初めて訪れた方は、まず[千手氏とは](../senju/)で起源と歴史的展開の概要を読み、そのあと次の順番で進むと全体像をつかみやすくなります。

## まず、時代を知る

[日本史と千手氏の系統別並列年表](../timeline/)は、同じ時代に各系統がどのような動きをしていたかを比較する、当サイトの中心となるページです。現在はレイアウト見本の段階で、史実データはまだ掲載していません。

## 次に、系統をたどる

[系統から探す](../lineages/)では、筑前（嘉麻・夜須）、豊前香春、日向高鍋、肥前小城などの地域・系統ごとに情報をまとめていきます。

系統の名称は、歴史的に使われた名称と、研究上の便宜的な呼称が一致するとは限りません。当サイトでは、その違いが分かるように記述します。

## 人物や史料へ進む

[人物から探す](../persons/)では個々の人物の記事、[史料から探す](../sources/)では古文書・古記録・系図・編纂物などの解題や個別記載を公開する予定です。

史料の記述と、編纂者による推定・考察を区別して読み進められるようにします。

## 調査に役立つ外部資料を探す

[関連機関・史料調査リンク](../links/)には、千手氏の関連地域を扱うサイトや、原史料の所在を調べるための主要な検索サービスを厳選して掲載します。

## 記述の読み方について

- **史料記載**：資料に実際に記されている内容。史実としてそのまま確定するとは限りません。
- **伝承・由緒**：後世に伝えられた来歴や説明。
- **推定・考察**：史料や地理・年代などを比較した編纂者の判断。
- **未確認**：照合・検証が済んでいない事項。空欄が史実の不存在を意味するわけではありません。

詳細は[編纂方針](editorial-policy.md)をご覧ください。

このWebサイトは構築中です。並列年表と人物・史料ページには、現時点では表示確認用の枠組みが含まれています。本文が整った段階で、典拠を確認した記事から公開します。
