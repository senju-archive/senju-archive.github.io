# 引用・利用案内

<div class="archive-status">運用方針整備中</div>

千手氏歴史アーカイブの文章や史料情報を参照する際は、読者が参照元を確認できるよう、記事名・サイト名・URLなどを明記してください。

## 記事を参照する場合

一般的には、次の情報を併記すると参照しやすくなります。

- ページのタイトル
- サイト名「千手氏歴史アーカイブ」
- 記事に記載された編纂者・公開日・更新日（記載がある場合）
- 該当ページのURLと閲覧日

記事中で引用した古文書・図版・翻刻は、当サイトが権利を保有しているとは限りません。元の資料や所蔵機関の利用条件も確認してください。

## 史料・画像の二次利用

資料画像・写真・他者の翻刻・研究成果は、それぞれ権利者や所蔵機関の条件が異なります。当サイトから閲覧できることだけをもって、転載・再配布が自由に許可されるわけではありません。

## 訂正のご連絡

出典の誤記、人物同定、引用箇所などにお気づきの場合は、ご指摘の対象ページと根拠になる資料をお知らせいただけると検証に役立ちます。

ご連絡は[お問い合わせフォーム](../contact.md)からお願いいたします。
