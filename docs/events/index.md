# 事件・合戦から探す

<div class="archive-status">事件索引・表示構造を整備中 ／ 個別記事は未公開</div>

千手氏に関わる**合戦・城の攻防・移封・移住・主家の変動**などを、一つの出来事ごとに調べるための入口です。

ここでは「何が起こったか」だけでなく、**その時代の勢力関係と、千手氏のどの系統にどのような関わりが確認できるか**を、史料に基づいて整理します。

## 記事の一覧について

**現在、史料照合を終えた個別事件記事はまだ登録していません。** 年表や系統別概説に登場する歴史的な出来事を、そのまま未検証で独立記事にすることは避け、出典や経緯の確認が済んだものから順次掲載します。

具体的には、千手城をめぐる南北朝期の動向、香春岳城に関する伝承、九州平定後の秋月氏家臣団の移動などが、研究資料との照合を要する主題です。**これらは今後の調査対象の紹介であり、事件記事の公開や個々の千手氏の参戦を確定するものではありません。**

## 事件を読むときの注意

主家や同じ陣営に属する集団が戦ったことと、**個々の千手氏が現場にいたことは別の事柄**です。また、同じ時期に起きた変化と、それを直接引き起こした原因も区別します。

歴史的な名称・所属と、調査のための現代の系統呼称を混同せず、史料記載・後世の伝承・推定・未確認を区別して扱います。詳細は[編纂方針](../guides/editorial-policy.md)をご覧ください。
