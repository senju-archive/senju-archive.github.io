# 事件・合戦から探す

千手氏の歴史に関わる合戦、城の攻防、主家の変動、移封・移住などを、時代の流れに沿ってたどります。関係する人物や勢力、出来事を伝える史料にも注目します。

## 主な関連事項

- **南北朝期の千手城と周辺の軍事動向**――[南北朝時代の記録](../periods/nanbokucho/)／[筑前嘉麻千手氏](../lineages/chikuzen/)
- **香春岳城（鬼ヶ岳城）に関する伝承**――[室町時代の記録](../periods/muromachi/)／[豊前香春千手氏](../lineages/buzen/)
- **九州平定後の秋月氏家臣団の移動**――[安土桃山時代の記録](../periods/azuchi-momoyama/)／[日向高鍋千手氏](../lineages/takanabe/)

香春岳城の落城や千手氏の移動には、後世の軍記・系譜によって伝えられた内容も含まれます。出来事の年代や関係者については、各記録の記載に即して紹介します。
