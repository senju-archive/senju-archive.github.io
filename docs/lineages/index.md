# 系統・地域から探す

**現在の都道府県と歴史的な系統名**から、千手氏の活動地・時代・主家・史料をたどる入口です。[千手氏とは](../senju/)で全体像をつかんだ後、関心のある系統を選んでください。

現在の県名と、史料に現れる旧国・旧郡名を併記しています。
