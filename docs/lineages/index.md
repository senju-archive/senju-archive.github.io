## 系統分類を読む際の注意

この四分類は、**研究と閲覧のための標準呼称**です。すべての時代に当人が同じ地域名で名乗ったわけではなく、とくに日向移住前の人物は「秋月家臣の千手氏（後の日向高鍋系）」等と表記します。

- **筑前千手氏**の嘉麻・夜須の関係は、地理や関連史料に基づく研究上の論点です。
- **豊前香春千手氏**では香春期と金田定着後を区別します。
- **日向高鍋千手氏**と**肥前小城千手氏**は、同時期の動向が重なる場合も一つの系統として統合しません。
- **肥前小城千手氏**と佐賀藩本藩に仕えた可能性のある千手氏は、確認されるまでは同一視しません。

## その他の関連・派生系統

嘉麻小野谷桑野氏、筑前福岡千手氏、肥後熊本千手氏なども調査対象です。史料の整理が進み、独立記事として説明できる段階で追加します。

なお、肥前国巨瀬の**児玉党流千住氏**は、表記が似ていても筑前発祥の千手氏と別系統として扱います。

## 編纂の根拠と公開状況

この一覧と各系統の初稿は、当アーカイブの『【千手氏】起源考察・系統分類・標準呼称ガイドライン（公式リファレンス）』、『千手氏 古代中世編年史料』、『千手氏 近世（江戸）以降の記録』を基礎としています。

現在は**概説の初稿**です。個別史料の使用底本・巻・頁・画像位置を示す記事は順次公開し、後世の伝承と史料から確認できる事実を区別して補訂します。
