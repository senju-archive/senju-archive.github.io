# 豊前香春千手氏（のち金田定着）

## 概要

豊前香春千手氏（のち金田定着）は、豊前国田川郡の香春岳城（鬼ヶ岳城）との関わりを伝える系統です。室町初期の城主・千手信濃守興房と、落城後に西金田へ移ったと伝わる千手高房が、系統の推移を考える中心人物です。**香春での軍事活動と、金田に定着した後の歴史は区別**して整理します。

## 歴史の流れ

### 香春岳城をめぐる時期

千手氏の編年整理には、応永元年（1394年）に**千手信濃守興房が鬼ヶ岳城へ入った**とする記述があります。この時期の具体的な政治状況や城主としての活動は、後世の軍記・郷土史の記述と照合しながら検討します。

### 応永6年の落城伝承

応永6年（1399年）の香春岳城の落城で興房が自刃し、子の**千手弾正高房**が逃れたという話が伝えられています。合戦の細かな経緯、人物の続柄、その後の経路には史料上の異同があるため、伝承と確認できる記載を分けます。

### 西金田への定着と近世以降

福岡県田川地方の郷土史には、高房の後裔が西金田に定着したとする記述があります。金田の千手家に伝わったとされる**鎧兜や興房の肖像画**も、家の由緒と伝来を知る手がかりです。近世の在地社会や近代の活動についても、個別の史料を整理していきます。

## 関連人物・拠点

- **千手信濃守興房**――香春岳城主として記録・伝承に見える人物。
- **千手弾正高房**――落城後の移動・金田定着を伝える系譜の中心人物。
- **香春岳城（鬼ヶ岳城）**――室町期の主な活動地。
- **西金田**――後世の居住・家伝に関わる地。

## 研究上の論点

[筑前千手氏（嘉麻・夜須）](../chikuzen/)から豊前へ展開したとする理解について、人物同定・分岐の時期・城の支配関係を個別史料で確かめます。特に同名人物の存在や年代の食い違いがないかを検討し、**単に「高房」という名が一致するだけで同一人物と断定しません。**
