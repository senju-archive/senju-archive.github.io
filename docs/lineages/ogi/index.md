# 肥前小城千手氏

## 概要

肥前小城千手氏は、戦国末期に筑紫氏の家臣として活動したと伝わる千手氏と、のちに小城藩鍋島家に仕えた一門を調査対象とする系統です。千手喜雲の武芸に関する伝承や、小城藩士としての家系・俸禄の変遷などを取り上げます。**佐賀藩本藩の千手氏を、根拠なく小城藩系へ含めない**ことを原則とします。

## 歴史の流れ

### 戦国末期――筑紫氏との関係

筑紫氏に仕えた千手氏がいたとする記述があり、千手六之丞（後の千手喜雲とされる人物）の活動が伝えられています。宝満城に関わる戦闘やその後の移動については、軍記・系譜と同時代資料を区別して検討します。

### 近世――小城藩への仕官

千手喜雲が鍋島家に仕官したとする伝承や、小城藩創設期の家臣団に関する記述があります。藩士としての家格や家名の変化は、研究資料に残る系譜情報を整理したうえで、藩の記録と照合していきます。

### 武芸と家の伝承

千手喜雲は武術の流派**「角蔵流」**に関わる人物として伝えられています。流派の成立、伝承の継承、人物の事績を混同せず、それぞれの根拠を確認します。

### 江戸後期から幕末

家臣の役職・俸禄・系譜に関わる史料を手がかりとして、小城藩における千手氏の継続を調べます。

## 関連人物・拠点

- **千手喜雲（千手六之丞と伝わる人物）**――小城藩への仕官・武芸伝承の中心人物。
- **鍋島元茂**――小城藩の成立と千手氏の仕官関係を考える際の主家の人物。
- **肥前国小城**――近世以降の主な活動地。

## 研究上の論点

「肥前小城千手氏」は**小城藩系**の標準呼称であり、「肥前佐賀千手氏」を自動的に含むものではありません。佐賀藩本藩に独立した千手氏が確認された場合は別に整理します。

また、肥前国巨瀬に由来する**児玉党流の「千住氏」**は、表記も出自も異なるため、筑前を発祥とする千手氏とは混同しません。
