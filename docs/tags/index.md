# 関連タグから探す

<div class="archive-status">タグ別記事索引 ／ 公開済みのページから順次充実</div>

このページでは、**原田氏・秋月氏などの関連氏族**や、移封・城郭攻防・武芸などの共通テーマで公開済み記事を横断して探せます。

記事の末尾に表示されるタグを押しても、同じテーマの記事を一覧できます。**タグはその話題が本文に登場することを示す分類であり、人物同士の血縁関係や、事件への直接参加を証明するものではありません。**

## タグの読み方

- **関連氏族**：原田氏・秋月氏・筑紫氏・鍋島氏など、千手氏の歴史と関わる家。
- **研究テーマ**：移封・城郭攻防・藩校・武芸など。
- **時代と地域**：タグでは重複分類せず、[時代から探す](../periods/)・[系統・地域から探す](../lineages/)に集約します。

「#系統」「#千手氏」や四系統名などの重複タグは整理しました。表記違いや人物の異名を別タグにせず、本文や検索語で案内します。

## 目的の記事が見つからないとき

人物・地名・史料名を直接探したい場合は、サイト上部の**全文検索**や、[人物](../persons/)・[史料](../sources/)・[関連事典](../encyclopedia/)の索引を利用してください。未公開の記事は検索結果やタグ一覧には追加していません。
