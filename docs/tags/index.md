# タグから探す

<div class="archive-status">タグ別記事索引 ／ 公開済みのページから順次充実</div>

このページでは、千手氏の各系統・活動地域・時代など、**共通するテーマのある記事**をまとめて探せます。

記事の末尾に表示されるタグを押しても、同じテーマの記事を一覧できます。**タグはその話題が本文に登場することを示す分類であり、人物同士の血縁関係や、事件への直接参加を証明するものではありません。**

## タグの読み方

- **系統名**：「筑前千手氏」「豊前香春千手氏」「日向高鍋千手氏」「肥前小城千手氏」は当アーカイブの標準呼称を使用します。
- **地域名**：「嘉麻・夜須」「香春・金田」「高鍋」「小城」は、史料上の地名や現在の自治体名そのものではなく、閲覧用の話題分類です。
- **時代**：「中世」「近世」などは、当該記事が扱う時代の目安です。記事全体がその時代だけに属するという意味ではありません。

表記違いや人物の異名を別々のタグにして増殖させず、必要に応じて検索語や個別記事の異表記欄で案内します。

## 目的の記事が見つからないとき

人物・地名・史料名を直接探したい場合は、サイト上部の**全文検索**や、[人物](../persons/)・[史料](../sources/)・[史跡](../sites/)の索引を利用してください。未公開の記事は検索結果やタグ一覧には追加していません。
