## 表示の基本方針

- **PC**：日本史の時間軸と各系統を横に並べて比較します。
- **スマートフォン**：同じ時代の情報を縦に積み、横スクロールに頼らず読める形を目指します。
- **典拠**：年表の記述から人物・史料・事件などへたどれる導線を用意します。
