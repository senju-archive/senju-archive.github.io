# 日本史と千手氏の系統別並列年表

<div class="archive-status">レイアウト試験中・史料データ未掲載</div>

このページは千手氏歴史アーカイブの基幹コンテンツです。**日本史の出来事を共通の時間軸**として、同じ時代の千手氏各系統の動向を横断的に照らし合わせます。

## 表示方式の試作

PCでは左に年代・日本史を置き、各系統を独立した列で比較します。右側には、個別史料や人物記事へ進むための「典拠・関連情報」の欄を設けます。スマートフォンでは、同じ情報を時代ごとの縦積み表示に切り替えます。

## 今後の掲載内容

古代・中世／南北朝・室町／戦国／近世など、時代別に整理し、各出来事から **系統別通史・人物・事件・文献解題（DOC）・個別史料記録（SENJU）・史跡** へ進める構成を予定しています。

時代ごとの列数は固定せず、その時期に比較すべき系統に合わせて調整します。現在はPCとスマートフォンの表示を検証する段階です。
