## 関連人物

原田氏・秋月氏・筑紫氏など、**千手氏の歴史を理解するうえで関係のある人物**は、千手氏の人物より後の独立した欄に掲載します。関連氏族の記事を横断して探したい場合は[関連タグ](../tags/)を利用できます。

## 人物記事の並び順

千手氏を優先し、まず**系統別**、その中で**活動年代が古い順**に掲載します。系統の帰属が推定段階の人物、複数の系統が関連する人物、活動年代の分からない人物は、無理に特定の欄や年代に当てはめません。関連人物は活動年代順とし、五十音順は補助的な索引で用います。

人物を直接探すときはサイトの**全文検索**も利用できます。異表記・通称は根拠を確かめた上で本文中に収録していきます。
