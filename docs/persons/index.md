# 人物から探す

<div class="archive-status">構築中・データ登録前</div>

千手氏に関わる人物を、時代・系統・活動地・関連史料から探せる索引を準備しています。

人物記事には、確認できる事績と典拠、系図や伝承による記載、未確認事項を区別して掲載する予定です。

現時点では、公開用の人物レコードを掲載していません。

## レイアウトの確認

[人物記事の表示見本を見る](../previews/person/)

[事件・合戦から探す](../events/)では、複数の人物が関わる出来事を横断的に扱います。地名・史跡・関連氏族や制度の用語は[関連事典](../encyclopedia/)で解説します。

この見本はページ構造を確認するためのもので、実際の人物記事ではありません。
