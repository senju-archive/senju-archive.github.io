# 個別史料記載（SENJU）｜表示レイアウト見本

<div class="archive-status">3層構造の表示確認用 ／ 実史料は未掲載</div>

SENJUは、文献中の特定の記載や日付条を扱うページです。**親となるDOCを必ず指定**し、根拠の箇所を第三者が追跡できるようにします。

## 第1層｜概要

### どのような記述か

対象史料の要点を、一般読者が最初に理解できるように説明する領域です。この見本に史実の内容は入っていません。

### 歴史的な位置づけ

この記述が関わる人物・事件・系統の案内を表示します。

## 第3層｜出典と考証

### 出典・典拠情報

書誌、所蔵・請求記号、巻・頁・丁・コマ、利用底本、参照先などを示します。

### 史料批判と異説

成立事情、異本、他史料との照合、人物の同定、編纂者による補読などを区別します。
