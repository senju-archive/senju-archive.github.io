# 関連機関・史料調査リンク

<div class="archive-status">リンク集・初期掲載版</div>

千手氏の歴史・関連地域・原史料を調べる際に役立つWebサイトを、**研究対象との関連性と調査上の実用性**を基準に選んで紹介します。

歴史サイトを無差別に集めるのではなく、対象地域の郷土史や文化財を扱うサイト、史料の所在・本文を調べるための機関・検索サービスに絞っています。

## 千手氏の関連地域・郷土史

### 嘉麻市・千手周辺

- **[嘉麻市「歴史・文化遺産」](https://www.city.kama.lg.jp/life/2/15/)**  
  嘉麻市の文化財、文化施設、歴史関係の刊行物などへの案内。筑前国嘉麻郡千手の地域史を調べる入口です。
- **[嘉麻市「指定文化財」](https://www.city.kama.lg.jp/soshiki/27/2919.html)**  
  指定文化財の一覧。千手（古処山）を所在地とする文化財など、地域の歴史的環境を確かめられます。**掲載文化財が千手氏に直接由来するという意味ではありません。**
- **[嘉麻市の文化施設（郷土館など）](https://www.city.kama.lg.jp/soshiki/27/2935.html)**  
  嘉麻市碓井郷土館などの施設案内。地域の歴史・民俗に関する展示情報を確認できます。

この分野は、千手氏の活動地域に関わる地元の研究サイトや郷土史の公開情報を確認しながら、必要なものだけを追加していきます。

## 史料の所蔵先・本文を調べる

### 国立国会図書館

- **[国立国会図書館サーチ](https://ndlsearch.ndl.go.jp/)**  
  全国の図書館と連携する所蔵資料・書誌情報の検索。郷土史、家譜、地域史の出版物などの所在を調べるのに便利です。
- **[国立国会図書館デジタルコレクション](https://rekion.dl.ndl.go.jp/ja/)**  
  国立国会図書館がデジタル化した資料の検索・閲覧。資料によって閲覧条件が異なります。

### 国立公文書館

- **[国立公文書館デジタルアーカイブ](https://www.digital.archives.go.jp/)**  
  所蔵資料の目録や公開画像を検索できるサービス。資料の利用条件は各画面で確認してください。

### 東京大学史料編纂所

- **[東京大学史料編纂所・データベース検索](https://www.hi.u-tokyo.ac.jp/db/)**  
  日本史史料の書誌・目録・古文書・古記録などのデータベースへの入口。個別の史料データや画像の利用条件には注意が必要です。

## 掲載と連絡について

リンク先は紹介先であり、当サイトの運営・記述内容について、各機関・サイト運営者から推薦・承認を受けたことを意味しません。

掲載先の選定では千手氏との具体的な関連を重視します。必要に応じて、掲載のご報告や内容の確認のためにサイト管理者へ連絡することがありますが、**相互リンクをお願いすることを目的にはしていません。**

リンク切れや内容の変更が判明した場合は、随時見直します。
