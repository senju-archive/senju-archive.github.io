# 時代から探す

<div class="archive-status">時代別記事索引 ／ 登録・史料照合を順次進行中</div>

日本史の一般的な時代区分から、千手氏の関連情報を探せます。**各時代の中では四系統を混ぜ、年代の古い順に並べます。** 年代未詳の伝承や人物は、年代順の項目と区別して表示します。

並列年表は代表的な出来事を日本史と比較する入口です。一方、この時代別索引には、今後公開する**人物・事件・史料・史跡の記事を幅広く収録**していきます。

## 大正時代以降

大正・昭和・平成・令和の各時代については、掲載できる記録が整った段階で独立した索引を追加します。未公開の記事を架空の項目として置きません。

## 探し方の使い分け

**[並列年表](../timeline/)**は代表的な出来事の比較、**[系統・地域から探す](../lineages/)**は各系統の歴史、**[関連タグ](../tags/)**は原田氏・秋月氏など共通する氏族や研究テーマをたどるための入口です。

現在の時代別ページは、登録済み調査資料に基づく**暫定的な年代順案内**です。掲載された項目が原本照合済みの個別事件記事であることを意味しません。
