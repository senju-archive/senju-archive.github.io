# 時代から探す

日本史の一般的な時代区分から、千手氏の関連情報を探せます。各時代の記録を年代順に並べ、年代の分からない伝承や人物は別にまとめています。

時代ごとの出来事を調べる場合は、この一覧から各時代へ進めます。日本史との比較は[並列年表](../timeline/)もご覧ください。
