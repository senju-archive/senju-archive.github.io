# 千手氏とは

<strong>千手氏（せんじゅし）</strong>に関わる記録は、筑前国嘉麻郡、豊前国香春、日向国高鍋、肥前国小城など各地に残ります。当サイトは、それぞれの人物・家・史料を区別しながら調べています。

古文書・古記録に現れる人物、後世の系図に記された由緒、各地の地域史を通して、千手氏の歩みをたどります。

## 名字の由来と筑前の千手

筑前国嘉麻郡には「千手」という地名があり、後世の系図には、この土地に住んだとされる千手姓の人物が記されています。

千手氏の初期の姿を考えるうえでは、大蔵氏流の原田氏と、その一族に連なる秋月氏との関係が重要です。

『吾妻鏡』元暦2年（1185年）2月1日条には、原田種直の子息として「賀摩兵衛尉」が記されています。ただし、この条文に「千手氏」の名字はなく、この人物と後の千手姓の人物との関係は別の史料を用いて検討する必要があります。

一方、『美濃国諸家系譜』の「秋月氏系図」には、原田種直の子として**千手五郎種宣**が記され、「筑前国千手に住む」とする記載が見られます。後世にまとめられた系図のため、その親子関係や秋月氏との続柄には史料間の異同もありますが、千手氏の出自を検討する重要な資料です。

## 中世の千手氏

### 鎌倉時代――在地武士としての展開

原田氏の一族が秋月や千手の地に定着していく過程は、後世の系図や由緒書に伝えられています。特に鎌倉幕府から秋月荘を与えられたという話は広く知られていますが、当時の所領関係と照合する余地があるため、当サイトでは伝承と考証を分けて紹介します。

元亨3年（1323年）には「千手兵衛入道」に関わる書状の記録が見え、鎌倉時代末期には千手の名字を持つ人物が史料に現れます。

### 南北朝時代――千手城をめぐる争乱

南北朝の動乱期には、千手氏は秋月氏などとともに九州の南朝方の活動に関わったと記録されています。『嘉穂地方史古代中世編』には、建武4年（1337年）の千手・秋月氏らの軍事行動や、正平9年（1354年）の**千手城における軍忠**に関する記述が紹介されています。

千手城は、筑前における南朝方の戦いを考えるうえで重要な拠点の一つです。ただし、個々の合戦について誰がどの立場で参加したかは、史料ごとに確認する必要があります。

### 室町・戦国時代――所属と活動地の変化

室町・戦国時代の千手氏には、大内氏や秋月氏との関係を示す記録、豊前方面での活動、各地の武家への仕官を伝える系譜などがあります。戦乱や主家の変動のなかで、千手氏の活動地と立場も一様ではなくなっていきました。

こうした動きを、当サイトの[日本史と千手氏の系統別並列年表](../timeline/)で比較できます。さらに[時代から探す](../periods/)では、各系統の記事を混ぜて年代順に探せます。

## 千手氏の主な系統

地域ごとに、次の四つの千手氏に関する記録を紹介します。

### [筑前嘉麻千手氏](../lineages/chikuzen/)

筑前国嘉麻郡の千手とその周辺に関する記録をたどります。千手城、原田氏・秋月氏との関係、南北朝期以降の活動が主な話題です。

### [豊前香春千手氏](../lineages/buzen/)

豊前国田川郡の<strong>香春岳城（鬼ヶ岳城）</strong>にまつわる千手信濃守興房・高房の伝承や、西金田への移住を伝える由緒を紹介します。

### [日向高鍋千手氏](../lineages/takanabe/)

秋月氏の家臣団に関わり、のちに**日向国高鍋**へ移ったと伝えられる千手氏です。高鍋藩士、藩校明倫堂、近代の地域行政に関わる人物を紹介します。

### [肥前小城千手氏](../lineages/ogi/)

**肥前国小城藩**に仕えた千手氏に関する記録をたどります。千手喜雲の武芸伝承、鍋島家への仕官、小城藩士の系譜などを取り上げます。

このほか、嘉麻小野谷の桑野氏、筑前福岡・肥後熊本の千手姓に関する記録もあります。

## 古い伝承をどう読むか

千手氏には、天智天皇の時代に供奉した一族が千手の地に留まったとする伝承や、平家の落人を祖とする伝承も残されています。

これらは後世に伝えられた由緒であり、古代・中世の出来事を同時代に記録した史料とは性格が異なります。

なお、肥前巨瀬の武蔵児玉党流<strong>「千住氏」</strong>は、名字の字が異なる別系統として伝えられています。
