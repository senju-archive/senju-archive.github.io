# 千手氏とは

<div class="archive-status">千手氏の歴史・全体概要 ／ 順次補訂中</div>

<strong>千手氏（せんじゅし）</strong>は、筑前国嘉麻郡千手（現在の福岡県嘉麻市千手）を歴史的な拠点とする武士の一族です。中世の千手氏は、原田氏・秋月氏との関わりが伝えられ、古処山を挟む嘉麻・夜須地域を舞台に活動しました。のちには豊前国香春、日向国高鍋、肥前国小城など、各地に千手氏の系統が見られます。

その歴史は、一つの系図だけで説明できるものではありません。当サイトでは、古文書・古記録、系図、地域史、伝承を照らし合わせ、**いつ、どこで、どのような千手氏が活動したのか**を明らかにしていきます。

## 名字の由来と筑前の千手

千手という名字は、筑前国嘉麻郡の地名「千手」に結びつくと考えられます。千手の地は古処山の北東側にあり、山を隔てた南西側の秋月・夜須地域とも歴史的なつながりを持っています。

千手氏の初期の姿を考えるうえでは、大蔵氏流の原田氏と、その一族に連なる秋月氏との関係が重要です。

『吾妻鏡』元暦2年（1185年）2月1日条には、原田種直とともに戦った子息として「賀摩兵衛尉」が登場します。この記録自体に「千手氏」という名字は現れませんが、**原田氏の一族が源平合戦のころから嘉麻の地名を名乗っていた**ことを示す手がかりです。

一方、『美濃国諸家系譜』の「秋月氏系図」には、原田種直の子として**千手五郎種宣**が記され、「筑前国千手に住む」とする記載が見られます。後世にまとめられた系図のため、その親子関係や秋月氏との続柄には史料間の異同もありますが、千手氏の出自を検討する重要な資料です。

当サイトでは、嘉麻と夜須を初期の一体的な活動地域として捉え、**「筑前千手氏（嘉麻・夜須）」**という標準呼称を使用します。ただし、両地域の具体的な分掌関係は、現在も検討を続けている研究上の仮説です。

## 中世の千手氏

### 鎌倉時代――在地武士としての展開

原田氏の一族が秋月や千手の地に定着していく過程は、後世の系図や由緒書に伝えられています。特に鎌倉幕府から秋月荘を与えられたという話は広く知られていますが、当時の所領関係と照合する余地があるため、当サイトでは伝承と考証を分けて紹介します。

元亨3年（1323年）には「千手兵衛入道」に関わる書状の記録が見え、鎌倉時代末期には千手の名字を持つ人物が史料に現れます。

### 南北朝時代――千手城をめぐる争乱

南北朝の動乱期には、千手氏は秋月氏などとともに九州の南朝方の活動に関わったと記録されています。『嘉穂地方史古代中世編』には、建武4年（1337年）の千手・秋月氏らの軍事行動や、正平9年（1354年）の**千手城における軍忠**に関する記述が紹介されています。

千手城は、筑前における南朝方の戦いを考えるうえで重要な拠点の一つです。ただし、個々の合戦について誰がどの立場で参加したかは、史料ごとに確認する必要があります。

### 室町・戦国時代――所属と活動地の変化

室町・戦国時代の千手氏には、大内氏や秋月氏との関係を示す記録、豊前方面での活動、各地の武家への仕官を伝える系譜などがあります。戦乱や主家の変動のなかで、千手氏の活動地と立場も一様ではなくなっていきました。

こうした動きを、当サイトの[日本史と千手氏の系統別並列年表](../timeline/)で比較できます。さらに[時代から探す](../periods/)では、各系統の記事を混ぜて年代順に探せます。

## 千手氏の主な系統

現在の調査では、次の四つを主要な標準系統として整理しています。これらは調査・案内のための呼称であり、過去のすべての時代に同じ地名で名乗っていたという意味ではありません。

### [筑前千手氏（嘉麻・夜須）](../lineages/chikuzen/)

古処山周辺の**嘉麻郡千手・夜須郡千手**を中心とする、千手氏の初期の活動を考える際の母体的な系統です。千手城や秋月氏との関係、南北朝期の軍事活動、中世の地域社会とのつながりを調査対象としています。

### [豊前香春千手氏（のち金田定着）](../lineages/buzen/)

豊前国田川郡の**香春岳城（鬼ヶ岳城）**との関わりを伝える系統です。千手信濃守興房や千手高房に関する記録・伝承があり、のちに西金田へ定着した一族の近世以降の歴史へつながります。

### [日向高鍋千手氏](../lineages/takanabe/)

秋月氏に仕え、のちに**日向国高鍋**へ移ったとされる系統です。秋月家の移封と家臣団の移動を背景に、高鍋藩士としての歩みや、藩校・地域行政に関わった人物などをたどります。日向への移住以前の人々については、後世の「高鍋」という呼称と、当時の所属・居住地を区別して記述します。

### [肥前小城千手氏](../lineages/ogi/)

**肥前国小城藩**に仕えた千手氏の系統です。千手喜雲や武芸の伝承、鍋島家への仕官、小城藩士としての系譜などが主な調査対象です。佐賀藩本藩に仕えた可能性のある別系統とは、史料で確認できるまで混同しません。

ほかにも、嘉麻に残った一門と伝えられる**嘉麻小野谷桑野氏**、筑前福岡や肥後熊本で確認される千手氏など、関連・派生系統の調査を進めています。

上の各系統名を押すと、その系統の概要記事へ進めます。

## 古い伝承をどう読むか

千手氏には、天智天皇の時代に供奉した一族が千手の地に留まったとする伝承や、平家の落人を祖とする伝承も残されています。

これらは地域に伝えられてきた由緒として重要ですが、**伝承の内容が、そのまま7世紀や12世紀の出来事として確認されたわけではありません。** とくに古代の開祖伝承と、中世に地名を名字として名乗る武士の成立は、区別して考える必要があります。

また、字が似た**「千住氏」**もすべて千手氏と同じではありません。たとえば肥前国巨瀬を拠点とした児玉党流の千住氏は、筑前を拠点とした千手氏とは別系統として扱います。
