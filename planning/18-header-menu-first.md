# 18｜ヘッダーの小ロゴを外してメニューを左端へ（2026-10-22）

Android実機で、トップの題字・本文の正式蓮華ロゴが十分目立つことを確認。上部の深緋ヘッダーにさらに同じロゴを置く必要はなく、利用者から左端にメニューアイコンを出す要望があったため変更。

- Zensicalヘッダーの上部小ロゴのリンク／imgだけを削除し、メニュー（`__drawer`ラベル）をヘッダーの最初の操作要素にする。
- 明朝体のサイト名はこれまでどおりホームへのリンクとする。右端の検索は維持。
- ロゴ原本のファイル・トップ本文中の大きなロゴ・ブラウザのファビコンは一切変更しない。
- PC・スマホの両方でメニューの操作領域を確保。リンク検証に、ヘッダーの小ロゴなし・メニュー先頭・サイト名からホームへの案内あり、を追加。
- 最終版のサイト仕様書と運用ルールはサイトの構造とデザインが一通り完成してから改訂する。
