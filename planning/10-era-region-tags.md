# 10｜時代別入口・系統地域・タグ整理
2026年10月22日、ユーザーとの制作方針に基づいて更新。

- 並列年表：主要な歴史的出来事を比較。
- 時代から探す：平安、鎌倉、南北朝、室町、戦国、安土桃山、江戸、明治など、学校で馴染みのある時代区分を使用。四系統を混ぜて年代順に掲載、年代未詳は別枠。
- 古代の伝承は同時代史料で確認された事実とは区別。「古代（飛鳥・奈良時代）」に整理。
- 大正以降は史料登録に合わせて項目追加。
- 系統・地域から探す：現在の福岡・宮崎・佐賀の県をカードで大きく表示。元の四系統分類・色は維持。旧URLも維持。
- タグ：系統名、地域、時代を重複して付けず、原田氏・秋月氏・鍋島氏などの氏族および移封・藩校等の共通テーマを選択。タグ一覧URLは維持するがサイドメニュー独立枠は外す。
- 史料の個別記事は今回作成していない。時代別の年代は『千手氏 古代中世編年史料』『千手氏 近世（江戸）以降の記録』の研究整理を手掛かりにした暫定表示で、原典の巻頁・写本異同・著作権確認が済んだことを意味しない。
- 後続段階では単一の公開記事を複数の時代別索引に参照させ、別原稿への重複入力を避ける。
- GitHub Actionsで生成HTMLのタグ・県名・各時代URL・年代順を検証する。
