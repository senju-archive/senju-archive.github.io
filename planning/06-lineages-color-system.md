# 06｜四系統識別色・系統別概説・並列年表への適用

2026年10月22日、仕様書第3.1改訂版 8.3「系統別識別色」を実装。

## 色の設定（CSS）
- 筑前千手氏（嘉麻・夜須）：深緋 `#8E1F24`
- 豊前香春千手氏（のち金田定着）：金茶系 `#B8860B`、小文字等は濃金茶 `#77530B`
- 日向高鍋千手氏：藍鉄 `#2C4F64`
- 肥前小城千手氏：深緑 `#26593F`

## 掲載ページ
- `/lineages/`: 四系統の2列（スマホ1列）カード索引、凡例と呼称の注意
- `/lineages/chikuzen/`: 筑前千手氏（嘉麻・夜須）の概説
- `/lineages/buzen/`: 豊前香春千手氏（のち金田定着）の概説
- `/lineages/takanabe/`: 日向高鍋千手氏の概説
- `/lineages/ogi/`: 肥前小城千手氏の概説
- `/timeline/`: 四つの列の色・系統名・リンク・凡例
- `/senju/`: 主な系統からの色別直接リンク
- `/index/`: 系統案内文の更新（実際のトップ URL は `/`）

## 実装方針
- 明細セルの色と文字ラベルを併用する。色のみで識別させない。
- グローバルの金茶 `#C59B27` と豊前系統の金茶 `#B8860B` は用途を混同しない。
- PC年表は四列独立、スマホは同一内容の時代別縦積み。高鍋＋小城の合体セルは不使用。
- 固有ID・Notion管理番号は公表しない。
- 人物・事件記事の公開時は標準系統タグと `ln-*` の対応を再利用する。
- 過去の移住以前の「高鍋」「小城」を当時の居住地と誤記しない。
- 今回の歴史概説は、公式標準呼称ガイドライン・千手氏古代中世編年史料・近世以降の記録を元に執筆した。底本の巻頁・原画像への直接照合は未完成。後続の個別史料記事で検証・補訂する。

## 表示チェック（リリース後）
- PC: 全4枚のカード色と年表4列色、リンク
- スマホ: カードが1列になり、年表が時代単位で縦積みされる
- キーボード: 四系統リンクが文字でも識別でき、フォーカスが視認できる
