# 11｜関連事典と関連タグのメニュー化

2026年10月22日。「高鍋藩の存寄」のような用語や嘉麻市のような地名を解説できる場所が必要となったため、ユーザーの希望で「史跡」メニューを「関連事典」に変更し「関連タグ」をメニューへ復帰。

- 千手氏に関係する周辺知識のための事典。分類：地域・地名、城郭・史跡・寺社、関連氏族、制度・用語。
- 本文の人物・事件・史料と役割を分け、内部リンクで接続する。
- 既存の `/sites/` は削除せず、関連事典内の史跡索引として残す。
- `/encyclopedia/` に新索引を、`/previews/encyclopedia/` に個別記事の共通表示見本を設置する。
- 嘉麻市、存寄、秋月氏などは記事候補。未検証の専門用語解釈や史実を作らない。個別記事は原史料照合の後に公開する。
- 「関連タグ」はタグ重複整理方針を維持し、メニューに再表示する（従来の `/tags/` を維持）。
- 記事の一覧ページと案内ページからも事典へつなぐ。
- GitHub Actionsの生成HTML検査では、索引と従来の史跡リンク、プレビューを検証する。
