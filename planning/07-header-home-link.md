# 07｜ヘッダーからホームへ戻る

2026年10月22日：スマートフォンからメニューを開かずにトップへ戻れるようにする。

- Zensicalの標準ヘッダーではロゴのアイコンは既にホームへのリンクだが、サイト名と現在のページタイトルは文字表示だけだった。
- `overrides/partials/header.html` はZensical UIの正式なヘッダーテンプレート（MITライセンス）を原型とし、サイト名とページタイトルの両方に同一のホームリンクを設定。
- `zensical.toml` で `[project.theme].custom_dir = "overrides"` と `[project.extra].homepage = "https://senju-archive.github.io/"` を指定。既存のロゴリンクと一致。
- テーマ本来のハンバーガー・検索・タイトル切替・ページナビは維持。
- CSSではリンク装飾・フォーカス可視性のみ調整。正式な画像ロゴの追加は今後のデザイン工程。
- PC・スマホ共に、各サブページのヘッダーのサイト名／ページ名のいずれをタップしてもトップへ戻るようにする。
- テーマアップグレード時は独自ヘッダー部分の差分を再確認する。

確認手順：①/lineages/等のページを開く ②ヘッダーのサイト名をタップしてホームへ ③ページをスクロール後、ページ名からもホームへ ④メニューボタンと検索が従来通り開くこと。
