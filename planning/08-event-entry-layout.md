# 08｜事件・合戦記事の一覧・共通レイアウトと関連導線

根拠：『Webサイト全体設計・システム仕様書 第3.1改訂版』4.1、5.6、6.5、6.6 節、『HP記事執筆レギュレーション 第3.1改訂版』2、4.2、5、6、8、12節。

## 今回の公開

- `docs/events/index.md`：事件・合戦の入口。個別記事はまだ公開せず、目的・編集方針・関連一覧を掲載。
- `docs/previews/event/index.md`：事件詳細記事1件分の共通レイアウト。実在事件、日付、人名、史料の仮データは登録しない。
- `zensical.toml`：「事件・合戦」を左ナビに追加。
- `docs/index.md`：イベントへの第4の入口カードを追加し、7つのカードを整理。
- `docs/timeline/index.md`：現在の表示見本で、関連情報列・本文末から事件索引へのリンクを設置。
- `docs/lineages/index.md` および四系統の `index.md`：事件入口へリンク。
- `docs/persons/index.md`、`docs/sources/index.md`、`docs/sites/index.md`：概念別入口から事件へリンク。
- 人物・SENJUの表示見本：事件記事の表示見本へ相互ナビゲーション。
- `docs/assets/css/extra.css`：関係勢力・構成概要のカード表示（PC2列、スマホ1列）。

## 事件記事の編集要件

- 基本情報：記事名、別称、時期・範囲、場所、種別、関係系統、根拠状態。
- 第1の読者向け説明：概要、背景、関係勢力・人物、時系列、結果、各系統への影響。
- 史料を読む：必要に応じて個別記載（SENJU）と文献解題（DOC）のリンク。無許可の全文転載なし。
- 出典と考証：書誌、所蔵、巻/頁/丁/コマ、成立、伝来、史料間比較、異説を区別。
- 末尾：関連人物・系統・時代・史跡、編纂・改訂履歴。
- イベントの内部管理IDは公表しない（DOC/SENJUと同様、人物・事件・史料の追跡に必要なのは出典等）。
- 事件記事は史料記載（SENJU）や文献解題（DOC）と混同しない。
- 主家の参戦と個々の千手氏の参加、同時期性と直接因果関係を混同しない。
- 四系統の名称と活動時期の実際の所属を区別し、特に高鍋・小城を統合しない。

## 導線と次回以降

1. 現状：年表⇔事件索引、系統⇔事件索引、人物/史料/史跡⇔事件索引。
2. 本格公開時：年表の具体的出来事から公開イベント記事の固有URLへ、イベント記事から該当人物・DOC/SENJU・史跡の固有URLへ双方向リンク。
3. 公開前にユーザーがイベント原稿の典拠・利用条件・人物の同定・日付・因果関係を確認する。
4. URLスラッグは可読な事象名を用い、Notion内部管理用IDを公開URLに必要以上露出させない。
5. 実際のイベント記事の生成は、史料照合と公開審査が済んだ後に行う。

## 表示・動作確認

- PC: 左ナビ「事件・合戦」、トップの入口、2列表示、サイドバー保持。
- スマホ: ハンバーガーメニュー、1列表示、横スクロール発生なし、ヘッダーからホームに復帰。
- 概念リンク: 年表→事件一覧→レイアウト見本→人物/史料/史跡/系統の索引の往復。
- DOC/SENJU/人物の表示見本から事件表示見本へ。
