# 09｜本文の固有名詞リンク・標準タグ・関連記事の横断検索

2026年10月22日。『Webサイト全体設計・システム仕様書 第3.1改訂版』4.1・標準タグと発見可能性、『HP記事執筆レギュレーション 第3.1改訂版』6.2・6.3・8節に準拠。

## 目的

「人名・地名・事件名・史料名の初出から個別記事へ」「記事末尾のタグから同じ主題の複数記事へ」「記事末尾の関連項目から直接関係する記事へ」という3方向を組み合わせる。

## 今回の実装

- `zensical.toml` に `[project.plugins.tags]` を設置。閲覧用標準タグの許可リストを設定し、入力表記ゆれによるタグの分裂を防ぐ。
- `docs/tags/index.md` に `<!-- material/tags -->` を設置。Zensicalネイティブのタグ別ページ一覧を生成する。
- `docs/senju/index.md` と四系統の概説記事にYAML front matterの `tags` を付与。未公開事件・人物・史料のプレビューや単なる索引には個別歴史事実のタグを付けない。
- 「千手氏とは」内の四系統の見出しを、それぞれの公開済み系統ページへ直接つながるMarkdownリンクに変更。
- 豊前香春・日向高鍋の記事内に、筑前千手氏のページへの文脈付きリンクを付けた。本文は親子関係を断定せず、あくまで比較検討先。
- トップ・初めての方へ・系統一覧にタグ一覧ページへの入口、四系統記事末尾にタグ一覧へのリンクを設置。

- 表記ゆれは本文の異名・通称と検索で吸収。別表記だけのタグを増やさない。
- タグは**記事が対象を扱うこと**を表す。系統・事件・人物の同一性や関係性の学術的確定を意味しない。
- 時代タグ（中世・近世）は厳密な期間の所属ではなく、その時代に関連する記述が実際に含まれることを示す。
- 分類の追加・改名は公式の標準呼称ガイドラインと一致するように管理する。

## 将来の編集ルール

1. 人名・地名・事件名・史料名の初出リンクは、リンク先の個別記事が**公開済み**であり対象の同定が適切な場合だけ張る。
2. URLは公開相対リンクを使う。未公開ページへの404リンクは追加しない。Obsidian `[[ウィキリンク]]` を直接公開しない。
3. DOC/SENJU IDはNotion内部管理用。公開タグや記事本文に表示しない。
4. 記事末尾に「関連記事・人物・史料・場所」への**直接関係のあるリンク**を少数掲載する。タグだけで関連記事を無条件に推薦しない。
5. 同名異人・千住氏／千手氏の異表記や各地の系統には厳密な同定を適用し、推定は推定として表示する。
6. 今は個別人物・史料・事件記事の公開がないため、本文中のリンクは系統の公開済み実ページを中心とする。記事が増えればリンクを編集・拡充する。

## 公開後の確認

- PC：記事末尾にタグ表示、タグを押すと `/tags/#...` に移動、一覧で該当記事へ進める。
- スマホ：タグチップが読め、横スクロールなし、ホームへ戻るヘッダーリンクは残る。
- 記事本文：`/senju/` の四系統見出しから実ページへ移動できる。
- 概説記事：相互関連ページ・年表・タグ一覧へ移動できる。
- Zensical 0.0.71 のビルドに失敗した場合は直ちに構成を確認し、必要ならタグ設定を修正する。
